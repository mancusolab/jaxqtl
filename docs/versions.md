# Version history

jaxQTL uses Git tags and GitHub releases for version history.

- `v0.2.1`: accept fractional abundance estimates in Poisson fitting, fixing Negative Binomial null-model
  initialization for quantifier-derived phenotypes.
- `v0.2.0`: cell-type-specific workflow documentation, dosage and MAF support, clearer invalid-result handling, and
  fixes to chromosome validation and model initialization.
- `v0.1.0`: first tagged beta release.

See the [GitHub releases](https://github.com/mancusolab/jaxqtl/releases) page for release notes and downloadable
artifacts.
