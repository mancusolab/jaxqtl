## Summary

The design separates transcriptomic state construction from interaction testing. `state-factor` selects one cell type, excludes the focal chromosome, applies a sparse PFlog transform with within-cell CLR and within-donor centering, and learns a donor-balanced low-rank basis. It writes chromosome-specific, unwhitened state factors as versioned artifacts without creating a dense cell-by-gene matrix.

`cis-state` aligns focal-gene counts with the matching LOCO factors, donor genotypes, offsets, and covariates, then fits an NB2 null model with absorbed donor fixed effects and donor-covariate-by-state nuisance terms. It combines standardized genotype-by-state scores into one omnibus statistic, projects nuisance effects from donor-level contributions, and calibrates the result through either Rademacher donor multipliers or donor-space moments. Fixed-shape blocks and streamed outputs bound memory while preserving alignment, numerical, and calibration diagnostics.

## Problem Statement

`jaxqtl` currently tests donor-level pseudobulk expression phenotypes. It cannot test whether cis genotype changes the within-donor relationship between single-cell expression and transcriptomic state. The new workflow must perform that test without treating cells as independent genetic samples, fitting one coefficient per variant-state pair, or materializing cell-by-cell, cell-by-donor, cell-by-variant, or cell-by-interaction matrices.

The workflow has two independent scientific components. `state-factor` constructs a low-rank, leave-one-chromosome-out (LOCO) factorization of within-cell-type transcriptomic similarity from raw sparse counts. `cis-state` fits an absorbed-donor negative-binomial null model for a focal gene and calibrates an omnibus cis-by-state score using donor-cluster contributions. Existing pseudobulk commands and data contracts remain unchanged.

## Definition of Done

1. `jaxqtl state-factor` and its library API construct cell-type-specific PFlog state factors from sparse raw counts without materializing the transformed cell-by-gene matrix.
2. LOCO mode excludes the focal chromosome before PFlog estimation, shifted-log transformation, and CLR centering, and writes one versioned factor artifact per autosome.
3. The learned basis removes donor means and balances donor contributions by default while returning unwhitened factors with their natural singular-value scaling.
4. The absorbed NB2 null fit agrees with an explicit donor-dummy reference for fitted means, nuisance coefficients, dispersion, likelihood, weights, and score residuals.
5. The omnibus score and nuisance-efficient donor contributions agree with explicit interaction-design calculations on small inputs while avoiding prohibited dense expansions at production scale.
6. Donor multiplier and donor-space moment calibration are implemented with deterministic randomness, explicit diagnostics, and fail-closed behavior.
7. Required donor covariates adjust for donor-covariate-by-state nuisance interactions. Genotypes are standardized; variant and state weight arguments are absent from the public API.
8. Reduced and full simulation suites report null rejection, power, convergence, and trace-estimation behavior. The selected default calibration controls type-I error at prespecified validation levels.
9. OneK1K-style benchmarks report compilation, warm runtime, peak memory, and allocation shapes for state construction and per-gene testing.
10. Existing commands, public contracts, and tests remain unchanged. All tests, Ruff checks, formatting checks, and type checks pass.

## Goals and Non-Goals

### Goals

- Test the joint null of no cis-genotype-by-state interaction for a focal gene under an NB2 cell-count model with unrestricted donor fixed effects.
- Treat donors, not cells, as the independent genetic units for primary calibration.
- Build reusable grouped-centering and absorbed-solve primitives without generalizing dense pseudobulk abstractions prematurely.
- Keep state construction sparse and matrix-free on CPU while keeping inference array-only and accelerator-compatible through JAX.
- Provide deterministic, versioned, alignment-safe inputs and outputs suitable for chromosome-wide reuse.

### Non-goals

- Estimating persistent cis-eQTL main effects in the cell-level model.
- Fitting or reporting individual variant-state interaction coefficients.
- Localizing a causal variant or biologically interpreting individual state-factor columns.
- Accounting for state-factor estimation uncertainty, kinship, or related donors.
- Adding H5AD, AnnData, or 10x Matrix Market input in this branch.
- Supporting arbitrary interaction covariance matrices or public variant/state weights.
- Replacing or changing existing `cis`, `nominal`, `trans`, or `compute-pcs` workflows.

## Mathematical Sanity Checks

- The automatic PFlog estimator is the through-origin least-squares solution for `v_g - mu_g = alpha * mu_g^2`. LOCO values use cached per-gene contributions: `alpha_-h = (A - A_h) / (B - B_h)`.
- The implementation form `log1p(4 * alpha * X)` differs from the reference shifted-log scale by a chromosome-wide multiplicative factor. It preserves sparse zeros and the learned right singular subspace; downstream whole-kernel normalization removes the global interaction-kernel scale. Tests must compare the documented convention explicitly.
- The donor-balanced operator factors `sqrt(D_w) C_D L J_q`, with cell weight `1 / (N * (n_i - 1))` for donors with at least two retained cells. Returned factors are `S = C_D L J_q V_r`, not weighted left scores.
- Donor fixed effects absorb every donor-constant main effect. Required donor covariates therefore enter only through donor-covariate-by-state nuisance interactions. A global intercept is absent.
- For NB2 with log link, the score residual is `(y - mu) / (1 + phi * mu)`. Expected cross-information between mean parameters and dispersion is zero because the derivative of the mean score with respect to dispersion is proportional to `y - mu`; this identity requires analytic and numerical tests.
- Standardizing each valid genotype column fixes the variant scale. The supplied state factors keep natural scaling. With public weights removed, `Gamma_jk ~ Normal(0, tau)` and the interaction kernel is the elementwise product of the standardized genotype kernel and the state kernel.
- The multiplier and moment methods calibrate `Q = ||sum_i t_i||^2` from donor-level efficient scores. They do not treat cells as independent.

- Blocking issues: none at the design level.
- Accepted risks: fixed estimated state factors; no kinship; finite bootstrap resolution; possible moment-approximation tail error; possible truncated-SVD convergence failure; device-specific floating-point differences.

## Solver Strategy Decision

- User preference: CPU sparse state construction with JAX CPU/GPU inference and a future-compatible backend boundary.
- Chosen strategy: Split the workload across a SciPy CPU state-factor backend, Lineax-backed reduced nuisance solves, a specialized JAX absorbed-IRLS loop, and a custom blocked donor-space operator.
  - State factorization: a SciPy `LinearOperator` over sparse counts with `svds`; benchmark PROPACK and ARPACK on representative shapes before fixing the default.
  - Absorbed weighted least squares: existing Lineax-backed QR or Cholesky solvers on the reduced nuisance system.
  - NB fitting: a specialized JAX IRLS loop that composes grouped weighted centering, reduced solves, and the existing NB dispersion update.
  - Cluster moment calculations: a custom donor-space block operator because the full contribution matrix is prohibited.
- Why this strategy: it keeps large sparse preprocessing on a mature CPU stack, uses existing JAX/Lineax machinery for small dense systems, and reserves custom code for the model-specific grouped and blocked operations that existing abstractions cannot express.

## Solver Translation Feasibility

- Summary: All required computations can be expressed through sparse CPU operator products, donor segment reductions, small dense solves, JAX control flow, and blocked donor-level matrix products.
- Blocking constraints: no current blocker; factorization backend and tolerance defaults require representative benchmarks.
- Custom-solver rationale: The absorbed NB loop and cluster contribution operator are model-specific. Forcing them through the existing dense `GeneralizedLinearModel` or per-variant hypothesis interface would allocate prohibited matrices and change existing public contracts.

## Layer Contracts

### Ingress

The initial `state-factor` adapter accepts:

- one SciPy CSR/CSC `.npz` count matrix with shape `M x q`;
- a Parquet cell table with `matrix_index`, `cell_id`, `donor_id`, and the selected cell-type column;
- a Parquet gene table with `matrix_index`, `gene_id`, and normalized chromosome.

The initial `cis-state` adapter accepts raw focal-gene counts, a versioned state artifact, a genoio-compatible genotype source, required donor covariates, optional cell covariates, offsets or library sizes, and gene/cis-window metadata.

Array-level contracts:

```python
construct_state_factor(
    counts,
    donor_index,
    gene_chromosome,
    *,
    rank,
    exclude_chromosome=None,
    pflog_alpha="auto",
    center_within_donor=True,
    balance_donors=True,
    ...,
) -> StateFactorResult

test_cis_state_interaction(
    y,
    G,
    S,
    donor_index,
    offset,
    donor_covariates,
    *,
    covariates=None,
    calibration=...,
) -> CisStateInteractionResult
```

`donor_covariates` is required. Genotype standardization is mandatory. The API has no variant-weight or state-weight parameters.

Rejection rules include duplicate or missing identifiers, axis/metadata mismatch, noninteger or negative counts, invalid donor indices, nonpositive offsets, missing donor covariates, nonfinite arrays, invalid rank, mixed cell types without opt-in, nonpositive PFlog estimates without an override, monomorphic variants after alignment, and insufficient informative donors.

### Pipeline

`state-factor` selects cells and usable genes, computes LOCO PFlog sufficient statistics, builds the implicit centered/balanced operator, learns right singular vectors, forms unweighted cell factors, and writes a complete versioned artifact only after all requested factor sets succeed.

`cis-state` reconciles donors and cells, selects the chromosome-matched state artifact, filters gene-specific noninformative donors, fits the absorbed NB null, constructs the observed and efficient cluster scores, calibrates the statistic, and appends a bounded result batch.

Validation-first checks run before sparse operator creation or JIT. Static configuration remains outside dynamic array inputs. Jitted kernels receive arrays or PyTrees of arrays only, with stable result structures and shape buckets for variant blocks.

### Numerics

- State construction uses host-side SciPy sparse arrays and matrix-free factorization.
- Inference uses an explicit x64 policy on CPU/GPU and records backend/dtype metadata.
- Parameterized runtime behavior may use final `eqx.Module` implementations; passive results remain colocated `NamedTuple` or equivalent immutable PyTrees.
- Structural failures raise at Python boundaries. Recoverable per-gene numerical failures return a stable status, actionable message, `pvalue = NaN`, and diagnostics. Jitted loops do not raise Python exceptions.
- Random calibration and simulation accept explicit JAX PRNG keys or CLI seeds and split them deterministically.
- No computation constructs `M x M`, `M x N`, `M x p`, or `M x (p*r)` arrays.

### Egress

State artifacts use a versioned directory with array files, Parquet cell/gene metadata, and a JSON manifest containing input hashes, schema version, ordering, selection/filtering, PFlog diagnostics, donor counts, solver configuration, singular values, convergence residuals, and approximation metrics. LOCO artifacts share a parent manifest and immutable cell/donor ordering.

`cis-state` writes bounded Parquet batches plus a run manifest. Each row includes the statistic, p-value, calibration method, Monte Carlo resolution/error, kernel scales, dimensions, informative-donor counts, dispersion, convergence status, and failure code/message.

CLI exit codes are `0` for a completed run with valid output, `2` for argument/usage failures, and `1` for input, reconciliation, state-factorization, or run-level numerical failure. Per-gene recoverable failures remain rows with non-success status; a run in which every gene fails returns `1`.

## Data Conversion and Copy Strategy

| Source | Canonical boundary | Copy mode | Rationale |
| --- | --- | --- | --- |
| Sparse `.npz` counts | SciPy CSR array on CPU | single materialization | Compressed NPZ cannot be memory-mapped as an operational sparse matrix; conversion normalizes once without densifying. |
| Cell/gene/donor Parquet | Polars lazy reconciliation, then NumPy arrays | single-copy fallback | Tables remain host-side until deterministic joins and filtering finish. |
| Genotypes | genoio donor-level block, then JAX array | single host-to-device copy per block | Preserve donor-level storage and existing genotype streaming. |
| State factors | versioned array artifact, then NumPy/JAX array | mmap where supported; otherwise single-copy fallback | Factors are dense but bounded by `M x r`; conversion occurs once at inference ingress. |
| Result batches | JAX/NumPy arrays to Polars/Parquet | single host transfer per batch | Tabular reconstruction occurs only at egress. |

Raw format-specific containers do not cross into inference or hypothesis kernels.

## Multi-Input Reconciliation Contract (Required When Multiple Tabular Sources Feed Numerics)

- Sources: count-matrix axes, cell metadata, gene metadata, state-artifact manifests, genotype donor samples, required donor covariates, optional cell covariates, and gene/cis-window metadata.
- Entity keys: `matrix_index` plus `cell_id` for cells, `matrix_index` plus `gene_id` for genes, normalized `donor_id` for donor tables and genotype samples, and normalized chromosome/gene identifiers for LOCO selection.
- Join type and rationale:
  - Count axes and their metadata require exact one-to-one coverage.
  - Factors and focal outcomes require exact cell and donor identity.
  - Required donor covariates require complete coverage of every retained donor.
  - Genotype alignment uses an explicit inner intersection preserving genotype-source order and records every excluded donor.
- Duplicate-key policy: reject duplicates before any join.
- Missing-key policy: reject missing cell/gene/factor/covariate keys; genotype-only or expression-only donors may be excluded only through the recorded intersection and minimum-donor checks.
- Row-order freeze policy: freeze donor order after genotype reconciliation and cell order after factor/outcome validation; convert categorical donor IDs to a dense zero-based index once.
- Reconciliation accounting: manifests report input, selected, matched, excluded, and gene-specific informative counts with reason codes.
- Conversion boundary: Polars performs key reconciliation; canonical NumPy/JAX arrays and PyTrees begin after ordering and accounting are frozen.

## Simulation And Inference-Consistency Validation

- In scope: yes
- Simulate entrypoint/signature: `simulate_cis_state(key, params, config) -> CisStateSimulation`
- Inputs: donor/cell/variant/state dimensions; genotype MAF/LD parameters; donor cell-count distribution; library-size distribution; state and donor-covariate distributions; nuisance effects; donor intercepts; NB dispersion; interaction variance or explicit `Gamma`; within-donor misspecification controls; zero-count scenario controls.
- Outputs: `y`, `G`, `S`, `donor_index`, `offset`, cell covariates, required donor covariates, true `mu`, `phi`, `Gamma`, informative-donor truth, and scenario metadata.
- Seed/RNG policy: accept a JAX key; split and fold in scenario and replicate identifiers deterministically; store seed/key metadata needed to replay each failed replicate.

### Assumption alignment

| Inference assumption | Simulation rule | Mismatch risk | Mitigation |
| --- | --- | --- | --- |
| NB2 variance `mu + phi * mu^2` | Draw counts through the existing `NegativeBinomial.sample` parameterization | Family sampling and fitted likelihood could drift | Moment tests and parameterization fixtures |
| Donor fixed intercepts | Generate unrestricted donor intercepts in the log mean | Extreme intercepts create all-zero donors | Include boundary scenarios and record truth |
| State and donor-covariate nuisance terms | Generate `S`, cell covariates, and donor-covariate-by-state effects explicitly | Omitted simulated terms can masquerade as interaction | Store every generated linear-predictor component |
| Standardized donor genotype | Generate donor-level dosage, then apply the same analysis standardization | Rare/monomorphic draws can change effective `p` | Record dropped variants and effective dimensions |
| Null `Gamma = 0` | Set interaction matrix exactly to zero | Numerical noise could be mistaken for alternative | Retain exact truth and deterministic replay |
| Alternative `Gamma_jk ~ Normal(0, tau)` | Draw an explicit matrix with increasing `tau` | Random effects may yield nonmonotone finite-sample power | Use enough replicates and report Monte Carlo intervals |
| Donor-cluster robustness | Add donor-specific latent state slopes or correlated substate effects in misspecified scenarios | Dependence form may be too narrow | Include multiple correlation strengths and structures |
| Population/state adjustment | Correlate donor genotype PCs with genotype and state distributions, then include required PCs in donor covariates | Unrealistic confounding strength | Report the generative correlations and sensitivity grid |

## Additional Considerations

- **Default calibration decision:** The implementation cannot choose the default from speed. The full simulation report must record the nominal levels, replicate counts, binomial tolerances, and observed rejection rates used for the decision.
- **Artifact atomicity:** A LOCO state run should expose either a complete validated manifest or a run-level failure. Incomplete chromosome artifacts must not be accepted by `cis-state`.
- **Module granularity:** The `state` subpackage is justified by a new durable domain boundary. Result types, small helpers, and exceptions remain colocated unless implementation demonstrates stable cross-module reuse. The final review must merge trivial leaf modules.
- **Future sparse backend:** The public state-result and artifact contracts are backend-neutral. No initial API exposes SciPy solver objects, allowing a future accelerator backend without changing `cis-state`.

## Glossary

- **Absorbed donor fixed effects**: Donor-specific intercepts eliminated algebraically rather than represented by explicit donor-dummy columns.
- **Calibration resolution**: The smallest p-value distinguishable with a finite number of random calibration replicates, approximately `1 / (B + 1)` for `B` replicates.
- **Centered log-ratio (CLR) centering**: Subtracting each cell's mean transformed expression across retained genes.
- **Cis / cis-eQTL**: A local genetic effect involving variants near the focal gene; a cis-eQTL is a local variant associated with that gene's expression.
- **Counts per million (CPM)**: Library-size normalization that rescales each cell or sample to one million total counts.
- **Donor balancing**: Weighting cells so each donor contributes equally when learning the state basis, regardless of cell count.
- **Donor centering**: Removing each donor's mean expression profile so state factors represent within-donor variation.
- **Donor cluster**: All cells from one donor, treated together as one independent unit for calibration.
- **Donor-space moment calibration**: Approximating the null distribution from moments of the donor-contribution covariance without forming the full covariance or interaction matrix.
- **Fixed-state interpretation**: Inference conditional on estimated state factors, without propagating uncertainty from their estimation.
- **Iteratively reweighted least squares (IRLS)**: An iterative method that fits a generalized linear model through a sequence of weighted least-squares problems.
- **Kernel**: A similarity matrix induced by features; here genotype and state kernels combine to represent genotype-by-state similarity.
- **Leave one chromosome out (LOCO)**: Constructing factors for a focal chromosome using only genes on other chromosomes, preventing focal-chromosome expression from entering the state representation.
- **Matrix-free operator**: A computation that provides matrix products without constructing or storing the full matrix.
- **Negative binomial 2 (NB2)**: A count model with variance equal to the mean plus dispersion times the squared mean.
- **Nuisance-efficient donor contribution**: A donor's interaction-score contribution after removing the component explained by fitted nuisance covariates.
- **Omnibus score test**: A joint test that combines evidence across all variant-state pairs into one statistic without estimating each interaction coefficient.
- **OneK1K-style scale**: A workload shaped like a large single-cell cohort with roughly one million cells and one thousand donors.
- **PFlog**: An overdispersion-adaptive shifted-log transform for raw counts whose zero-preserving form supports sparse computation.
- **Pseudobulk**: Expression counts aggregated across cells within each donor, usually within a cell type, before donor-level analysis.
- **Rademacher donor multiplier calibration**: A bootstrap-like procedure that repeatedly multiplies donor contributions by independent random signs and recombines them without refitting the null model.
- **Score residual**: The residual-like contribution from each observation to the fitted model's mean score.
- **State factor**: A low-rank cell coordinate whose cross-product approximates transcriptomic-state similarity; unwhitened factors retain their singular-value scaling.
- **Transcriptomic state**: A low-dimensional representation of within-cell-type expression variation used as the state axis of the interaction test.
